Git: A Máquina do Tempo

O Git é um sistema de controle de versão distribuído que roda localmente no seu computador. Ele salva fotografias (commits) de cada evolução do seu projeto, permitindo voltar no tempo caso algo dê errado.

☁️

GitHub: A Nuvem dos Devs

O GitHub é uma plataforma online que hospeda repositórios Git na nuvem. Ele permite compartilhar código, colaborar em equipe e exibir seus projetos para o mundo.

Comandos Essenciais do Dia a Dia

Estes são os comandos que você utilizará com mais frequência em sua carreira:

git status

Ver o Estado

Mostra quais arquivos foram criados, alterados ou estão prontos para commit.

git add .

Preparar Arquivos

Coloca as alterações na Staging Area (área de preparação antes da foto).

git commit -m "..."

Registrar Versão

Salva permanentemente a foto atual das alterações com uma mensagem descritiva.

git push

Enviar para a Nuvem

Envia os commits locais do seu computador para o repositório no GitHub.

git pull

Puxar Atualizações

Baixa alterações do repositório remoto para o seu computador local.

git branch

Gerenciar Ramificações

Cria e visualiza ramificações seguras para desenvolver novas funcionalidades.
